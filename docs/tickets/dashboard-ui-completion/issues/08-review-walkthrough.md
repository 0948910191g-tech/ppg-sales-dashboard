# 08: Review Walkthrough

**What to build:** Deliver the five-step Review Walkthrough shown in the reference: Signal, Context, Evidence, Insight, and Next Step. Carry the selected Review Signal into the walkthrough and present evidence and impact without issuing a business verdict or creating a persistent Action.

**Blocked by:** 06 — Review Attention Queue; 07 — Signal Context Drawer

**Status:** ready-for-agent

- [ ] Walkthrough opens from the selected signal and preserves its source, metric, period, platform, and category context.
- [ ] Five steps have clear current/completed/future states and keyboard-operable navigation.
- [ ] Evidence list, key-metric comparison, insight summary, business-impact cards, and suggested checks are visible.
- [ ] Read-only and static-sample disclosures remain visible where interpretation or action could be misunderstood.
- [ ] Back/close navigation restores the prior route and focus context without persisting an action.
- [ ] Focused walkthrough, keyboard, responsive, and reduced-motion tests pass.
